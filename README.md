# 🤖 Python Chatbot Suite

A collection of ready-to-run Python chatbots requiring **no external pip packages**!

---

## 📁 Included Chatbots

### 1. 🖥️ Desktop GUI Chatbot (`gui_chatbot.py`)
A modern desktop chat interface built with Python's built-in `tkinter`.
- **Offline / Local Mode**: Works instantly without any setup or internet.
- **AI LLM Mode**: Has a built-in settings window (`⚙️ Settings`) to plug in a Google Gemini or OpenAI API key.
- **Run command**:
  ```bash
  python gui_chatbot.py
  ```

---

### 2. 🧠 Terminal AI Chatbot (`ai_chatbot.py`)
A command-line conversational chatbot powered by real LLMs with multi-turn conversation memory.
- Supports **Google Gemini** (free tier available), **OpenAI (ChatGPT)**, and **Local Ollama** (100% offline).
- **Run command**:
  ```bash
  python ai_chatbot.py
  ```

---

### 3. ⚡ Lightweight Rule-Based Chatbot (`chatbot.py`)
A fast, offline command-line assistant.
- Handles greetings, calculations, tells jokes, checks time/date, and remembers your name.
- **Run command**:
  ```bash
  python chatbot.py
  ```
